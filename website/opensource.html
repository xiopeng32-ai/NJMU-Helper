Stack & Flow

一条请求穿过什么

没有自建服务器：应用只在本机发请求、本机解析、本机缓存。下面是登录到出数据的一次完整链路。

TS
ArkTS 严格模式静态类型 / 无 any 兜底
UI
ArkUI 声明式手机 / 平板 / 2in1 自适应
Web
ArkWeb 容器统一认证 / 云课堂内嵌
FM
FormKit 卡片桌面卡片与倒计时
V9
正方教务 V9课表 / 成绩 / 考试接口
CAS
金智统一认证多因子与设备信任

Contributing

三步，改成你学校

数据层与视图层解耦，绝大多数适配只落在配置与登录链路上。

01Fork & Clone

Fork 仓库后克隆到本地，用 DevEco Studio 打开，勾选自动签名完成一次构建。

02改配置

替换 config/ 中的学校域名、教务接口与登录地址，按新学校页面调整解析规则。

03提 PR

通用改动（性能、UI、解析容错）欢迎提回上游；学校专属改动留在自己的 Fork 即可。
