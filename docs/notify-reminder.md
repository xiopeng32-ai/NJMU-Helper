
## 通知与提醒（v2.0.16 新增）

### 能力边界（重要）
| 能力 | 应用未运行时能否工作 | 说明 |
|---|---|---|
| 课前提醒 | **能**（准时） | 系统代理提醒（reminderAgentManager），由系统托管 |
| 实况窗 | **不能准点弹出** | SDK 无时间触发器；仅在应用被打开/被后台任务唤醒且仍在 `[T-30, T+10]` 内时创建 |
| 后台刷新 | 能（不精准） | WorkScheduler 延迟任务，系统空闲时调度，通常 1~3 小时一次 |

### 实况窗时间轴
```
T-30 启动（胶囊=倒计时，系统每秒自刷）  →  T 切换「上课中」  →  T+10 停止（保留 60 秒后消失）
```
- `T+10` 的 10 分钟可在设置里改 5/10/15；上限受下课时间约束（`min(T+grace, 下课)`）。
- 若 `now ≥ T+10`，不再创建（记日志 `skip=expired`）。

### 开关（我的 → 通知与提醒）
总开关（默认关）/ 课前提醒 / 实况窗 / 实况窗收起延迟(5/10/15分) / 新成绩 / 教务公告 / 考试临近 / 后台刷新 / 提前分钟(10/15/30/60) / 滚动窗口(1/3/7天)

### 排查
日志页筛「流转 / 通知 / 提醒 / 实况窗 / 后台」：
- `[提醒] 对账 — 完成 计划N 新增M 撤销K`：排程是否生效
- `[实况窗] 创建 — 成功 … 存活N分`：创建成功及存活时长
- `[实况窗] 停止 — 成功 id=`：T+grace 是否按时停止
- `[后台] 刷新 — 成功 新增成绩X 新增公告Y`

### 已知限制
- 实况窗需 AGC 权益；未开通时自动降级为常驻通知（同样 T+10 撤销）
- 强行停止应用后代理提醒可能被清空，重新打开应用会自动补齐
- 通知权限未授予时 `publish` 静默失败，设置页会显示红色提示条
