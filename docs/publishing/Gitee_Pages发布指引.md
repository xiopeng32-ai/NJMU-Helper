# 隐私政策发布到 Gitee Pages · 操作指引

> 目标：把《隐私政策》发布成公开链接，得到形如 `https://你的用户名.gitee.io/仓库名/` 的 URL，供华为应用市场审核使用。
> 前置：已有 Gitee 账号（没有的话先注册 gitee.com，免费）。

---

## 一、文件已准备好

HTML 静态页已生成，路径：

```
邀测资料/隐私政策/index.html
```

> 文件名必须是 `index.html`，这样 Gitee Pages 才能把它作为首页自动打开。

---

## 二、操作步骤（在浏览器完成）

### 第 1 步：登录 Gitee
访问 https://gitee.com ，登录你的账号。

### 第 2 步：新建仓库
1. 点击右上角「+」→「新建仓库」。
2. 仓库名称填一个英文/拼音，例如：`njmu-helper-privacy`。
3. 路径会自动生成，保持默认。
4. 开源协议、模板等**都不用选**，直接点「创建」。
5. 创建后进入仓库页面。

### 第 3 步：上传 index.html
1. 在仓库页面点击「上传文件」按钮。
2. 把本机的 `index.html` 拖进去（或点「选择文件」）。
3. 提交信息可填「上传隐私政策」。
4. 点「提交」。

> 注意：`index.html` 必须放在仓库**根目录**（不要放到子文件夹里）。

### 第 4 步：开启 Gitee Pages
1. 在仓库页面顶部菜单点「服务」→「Gitee Pages」。
2. 在页面中：
   - 「部署分支」选 `master`（或 `main`）。
   - 「部署目录」选「/」（根目录）。
   - 「强制使用 HTTPS」建议开启。
3. 点「启动」或「更新」。

### 第 5 步：获取公开链接
1. 启动后，页面会显示一个访问地址，形如：
   ```
   https://你的用户名.gitee.io/njmu-helper-privacy/
   ```
2. **在浏览器无痕窗口打开这个链接**，确认能正常显示隐私政策内容。
3. 把这个链接复制下来，就是你要填入华为应用市场的"隐私政策 URL"。

---

## 三、常见问题

| 问题 | 解决 |
|---|---|
| 访问链接 404 | 确认 `index.html` 在仓库根目录，且 Gitee Pages 已「启动」 |
| 提示"未实名认证" | Gitee Pages 需要账号完成实名认证，按 Gitee 提示完成即可 |
| 部署后页面没更新 | 回到 Gitee Pages 页面点「更新」重新部署 |
| 想绑定自定义域名 | 高级功能，非必需，用默认 `xxx.gitee.io` 链接即可 |

---

## 四、拿到链接后

1. 把链接填入：AppGallery Connect → 版本信息 → 隐私政策栏位。
2. 同时建议在应用内"关于/设置"页面放一个隐私政策入口，指向该链接（华为审核建议应用内也提供入口）。
