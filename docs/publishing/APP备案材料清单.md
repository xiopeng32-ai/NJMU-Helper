# 南医助手 · 个人 APP 备案材料清单与办理流程

> 适用：个人开发者，HarmonyOS 应用（南医助手）
> 依据：华为开发者联盟官方文档 + 工信部备案政策（来源见文末），整理时间 2026-10-18

## ⚠️ 先看这个关键前提（决定成败）

个人 APP 备案**不能凭空办理**，监管要求备案与"一个已实名、已完成备案的网站（域名 + 服务器）"绑定。也就是说，你需要先具备：

| 前提 | 说明 | 是否需要 |
|---|---|---|
| **域名** | .cn 或 .com，已完成域名实名认证 | ✅ 必须 |
| **服务器/接入商** | 华为云/阿里云/腾讯云等，购买期限 ≥ 3 个月 | ✅ 必须 |
| **域名 ICP 备案** | 域名本身先完成 ICP 备案（1–3 天放行） | ✅ 必须 |

> 顺序是"套娃"式的：**买服务器 → 买域名 → 域名备案 → 再做 APP 备案**。有开发者从建申请到最终通过花了近一个月（来源：少数派《章法有度》）。**所以这一步必须现在就开始，别等代码写完。**

> ⚠️ 一个例外：纯单机应用（不联网）可豁免备案，但认定极严格——哪怕只是版本检查、崩溃上报等网络请求都会被判定为"非纯单机"。南医助手要联网抓取教务数据，**必定需要备案**，不要心存侥幸。

## 一、备案材料清单（个人开发者）

### 1. 主体资质（你本人）
| 材料 | 说明 |
|---|---|
| 身份证正反面 | 清晰扫描件/照片 |
| 手持身份证照片 | 人脸识别用 |
| 手机号 | 用于短信核验 |
| 邮箱 | 接收通知 |
| 本人真实姓名 | 备案主体必须填真实姓名，不是工程 vendor/团队名 |
| 身份证地址 | 填写地址须与身份证一致 |

### 2. 域名与服务器（接入商）
| 材料 | 说明 |
|---|---|
| 域名 | .cn/.com，已实名认证，已 ICP 备案 |
| 服务器 | 华为云/阿里云/腾讯云等，≥3 个月 |
| 接入商信息 | 服务器在哪家，就在哪家备案 |

### 3. App 特征信息（关键，从 AGC 提取）
| 材料 | 获取方式 |
|---|---|
| 鸿蒙包名 bundleName | AGC → 应用 → 包名（与工程 module.json5 完全一致） |
| 公钥 | AGC → 证书管理 → 下载发布证书 → 删除根/中间证书，保留叶子证书 → 详细信息-公钥 |
| 签名 MD5/指纹 | 同上，证书"详细信息-指纹"（SHA1，可当 MD5 用） |
| App ID | AGC → 应用信息 |

### 4. App 基本信息
| 材料 | 说明 |
|---|---|
| App 名称 | 南医助手 |
| 版本号 | 当前版本 |
| 功能简介 | 教务信息查询工具 |
| App 图标 | 已备 |
| 核心界面截图 | 3–5 张 |

### 5. 合规材料
| 材料 | 状态 |
|---|---|
| 隐私政策网址 | ✅ 已就绪：https://njmu-helper-privacy.app.workbuddy.host/ |

## 二、办理流程（总周期约 7–20 工作日）

```
① 买服务器 + 买域名（当天）
      ↓
② 域名实名 + 域名 ICP 备案（1–3 天）
      ↓
③ 从 AGC 提取包名/公钥/指纹（当天）
      ↓
④ 接入商平台提交 APP 备案（1 天）
      ↓
⑤ 接入商初审（1–3 天）
      ↓
⑥ 工信部短信核验（24 小时内点确认）
      ↓
⑦ 通信管理局终审（5–17 天）
      ↓
⑧ 拿到备案号 → 回填 AGC 备案信息
```

## 三、你可能还需要先做的两件事

### 1. 华为开发者实名认证（个人）
- 备案前建议先完成华为开发者个人实名认证，便于后续统一管理。
- 注册 developer.huawei.com → 个人认证 → 身份证 + 银行卡。

### 2. 确认你的服务器/接入商
- 如果**还没有任何云服务器**，需要先买一台（最便宜的轻量服务器即可，≥3 个月）。
- 推荐：华为云 / 腾讯云 / 阿里云任选，看价格和熟悉度。

## 四、常见驳回点（提前规避）

| 问题 | 规避 |
|---|---|
| 材料模糊 | 身份证/截图高清 |
| 隐私政策不全 | 已就绪 ✅ |
| 包名不一致 | 备案包名 = 工程 bundleName，三方一致 |
| 公钥/MD5 填错 | 从证书原件提取，别手改 |
| 域名未备案 | 先做域名备案，再做 APP 备案 |
| 主体填错 | 填真实姓名，不是 vendor |
