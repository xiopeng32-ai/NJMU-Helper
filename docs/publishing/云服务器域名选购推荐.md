# 云服务器 + 域名选购推荐（用于南医助手 APP 备案）

> 目标：用最低成本满足「个人 APP 备案」的接入商要求。
> 说明：文中价格为 2026 年公开活动价区间，**官方活动随时调整，下单前以官网实时价为准**。来源见文末。

---

## 一、结论：推荐「阿里云」

| 维度 | 阿里云 | 腾讯云 | 华为云 |
|---|---|---|---|
| 备案系统成熟度 | ⭐⭐⭐⭐⭐ 最成熟，流程标准化 | ⭐⭐⭐⭐ 体验流畅 | ⭐⭐⭐⭐ 严谨但更繁琐 |
| **APP 备案专项支持** | ⭐⭐⭐⭐⭐ 行业领先，有"智能预审" | ⭐⭐⭐⭐ 支持 | ⭐⭐⭐⭐ 支持 |
| 初审速度 | 1–2 工作日（部分省份 1 小时内） | 1–2 工作日 | 稍慢，补材料概率略高 |
| 身份核验方式 | App 人脸识别 | **微信小程序人脸识别（最方便）** | 必须用华为云 App |
| 轻量服务器价格 | 活动价约 38–68 元/年 | 活动价约 38–79 元/年 | 约 95 元/年起 |
| 学生优惠 | ✅ 有（学生认证后可领 300 元券） | ✅ 有（但专项优惠较少） | 较少 |
| 避坑点 | 续费涨价（首年价≠长期价） | 新注册域名需等 3 天才能备案 | 要求上传域名证书 |

**推荐阿里云的三个理由：**
1. **APP 备案专项做得最好**，"备案智能助理"能自动检测材料问题，显著降低被驳回概率——你第一次备案，这个最值钱。
2. **学生身份可薅羊毛**：完成学生认证后能领 300 元无门槛券，基本覆盖一台轻量服务器全年费用。
3. 初审快，流程指引清晰，个人开发者踩坑最少。

> 如果你更习惯微信操作，**腾讯云**也完全可以，人脸核验走微信小程序更省事，注意新域名要等 3 天再提交备案。

## 二、具体买什么（最低成本方案）

### 1. 服务器：轻量应用服务器（最低配足够）

| 项目 | 建议 |
|---|---|
| 产品 | 轻量应用服务器 / 云耀服务器（入门款） |
| 配置 | 2核 2G、3M 带宽、40G 系统盘（**备案不需要高性能**） |
| 地域 | **必须选中国大陆节点**（香港/海外节点不能备案） |
| 时长 | **≥3 个月**（系统会校验有效期，建议直接买 1 年） |
| 系统镜像 | 任意 Linux（Ubuntu/CentOS 均可） |
| 预算 | 约 38–100 元/年（活动价，以官网为准） |

> ⚠️ 这个服务器**不需要跑任何业务**，南医助手的数据是直连教务系统的。买它纯粹是为了拿到"接入商资格"，所以**买最便宜的就行**，别买高配。

### 2. 域名：越便宜越好

| 项目 | 建议 |
|---|---|
| 后缀 | `.top`（首年约 9 元）或 `.cn` / `.com`（约 55 元首年） |
| 要求 | 必须完成**域名实名认证**（个人：身份证） |
| 解析 | 解析到上面那台服务器 |
| 预算 | 9–60 元/年 |

> 💡 `.top`/`.xyz` 等便宜后缀完全够用，备案不看后缀高低。但如果你想让链接好看点，`.com` 也就多几十块。

### 3. 总成本估算

| 项目 | 费用 |
|---|---|
| 轻量服务器（1年） | 约 38–100 元 |
| 域名（1年） | 约 9–60 元 |
| 备案服务费 | **0 元**（接入商和工信部都不收费） |
| **合计** | **约 50–160 元** |

> 如果走学生认证 + 300 元券，实际支出可能接近 0。

## 三、下单到备案的行动顺序

```
第 1 天：
  ① 注册阿里云账号 → 完成个人实名认证
  ② 学生认证（学信网，秒过）→ 领 300 元券
  ③ 买轻量服务器（大陆节点，≥3个月）
  ④ 买域名（.top 最便宜）→ 完成域名实名认证
        ↓
第 2–4 天：
  ⑤ 域名 ICP 备案（阿里云备案系统提交，等待放行）
        ↓
第 5 天起：
  ⑥ 从华为 AGC 提取：包名 bundleName、公钥、签名指纹
  ⑦ 阿里云备案系统 → 新增「APP 备案」→ 平台勾「鸿蒙」
  ⑧ 上传：身份证、隐私政策链接、App 截图、备案承诺书
        ↓
第 6–20 天：
  ⑨ 阿里云初审（1–2 天）→ 工信部短信核验（24h）→ 管局终审（5–17 天）
        ↓
⑩ 拿到备案号 → 回填 AppGallery Connect 的「备案信息」
```

## 四、必须避开的 5 个坑

| 坑 | 说明 |
|---|---|
| ❌ 买成香港/海外节点 | 无法备案，白买 |
| ❌ 服务器时长 < 3 个月 | 系统校验不通过 |
| ❌ 域名没做实名认证 | 备案直接卡住 |
| ❌ 域名注册人 ≠ 备案主体 | 个人备案域名持有者必须是本人 |
| ❌ 把首年价当长期预算 | 续费通常翻几倍，第二年记得比价 |

## 五、备案时要用到的 App 信息（提前备好）

到阿里云备案系统时会让你填「App 特征信息」，这些要从华为 AGC 拿：

| 信息 | 获取路径 |
|---|---|
| 鸿蒙包名 bundleName | AGC → APP与元服务 → 应用 → 包名 |
| 公钥 | AGC → 证书、APP ID 和 Profile → 证书 → 下载发布证书 → 删掉根证书和中间证书，只留叶子证书 → 双击 → 详细信息 → 公钥 |
| 签名指纹（MD5/ SHA1） | 同上，证书"详细信息 → 指纹"（是 SHA1，接入商一般可当 MD5 用） |
| App ID | AGC → 应用信息 |
| 隐私政策链接 | ✅ 已就绪：https://njmu-helper-privacy.app.workbuddy.host/ |
| App 截图 | 3–5 张核心界面 |
