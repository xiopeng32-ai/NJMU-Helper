## 二、分步详解

### ① 华为开发者实名认证（个人）
1. 注册 HUAWEI ID → 访问 developer.huawei.com。
2. 选择"个人开发者"，提交：身份证、银行卡（用于实名核验）、手持身份证照片。
3. 认证通过后登录 **AppGallery Connect**。
- ⚠️ 个人账号与企业账号二选一，认证后不可互转；个人开发者受品类限制（不得涉及新闻、医疗、社交、电商等强监管领域，南医助手属教育工具类，个人主体可用）。

### ② 隐私政策 + 公开链接（今天就能搞定）
- 已为你生成《隐私政策.md》全文（见"邀测资料"文件夹）。
- **拿到公开链接的方式**（任选其一，个人开发者推荐前两种）：
  1. **GitHub Pages / Gitee Pages**：免费，把隐私政策发布成一个静态网页，得到 `https://xxx.github.io/...` 链接。
  2. **云服务商对象存储（COS/OSS）**：上传 HTML 文件，得到公开 URL。
  3. **腾讯文档 / 语雀 / 飞书**：发布为公开链接（需确认可公开访问）。
- ⚠️ 隐私政策 URL 是硬性要求，且审核会点开验证，必须是**公开可访问**的。

### ③ APP 备案（个人主体，最耗时的硬门槛）
- **为什么必须**：工信部《移动互联网应用程序备案工作的通知》要求，APP 主办者须履行备案手续，未备案不得上架。
- **办理入口**：通过你的**接入服务商**（腾讯云/阿里云/华为云）提交，或直接通过工信部备案系统。
- **个人主体材料**：身份证、手机号、邮箱、手持身份证照片、APP 截图。
- **技术信息**：包名（bundleName）、公钥/MD5 指纹（从开发者证书提取）、后台域名（如有）。
- **流程**：接入商初审（1–3 天）→ 工信部短信核验 → 通信管理局终审（5–17 天）。
- **总周期**：约 7–20 个工作日。
- ⚠️ 备案包名必须与工程 module.json5 的 bundleName **完全一致**。

### ④ 软件著作权（可选，但强烈建议）
- **作用**：华为应用市场大陆非游戏应用，软著为"非必选资质"，但提供软著可显著提高审核通过率，且是知识产权保护。
- **个人申请材料**：身份证正反面、源代码（前后各 30 页，每页 ≥50 行，页眉标注软件名+版本号）、说明书（≥10 页，图文）。
- **入口**：中国版权保护中心官网（ccopyright.com.cn）。
- **周期**：普通 30–60 工作日，加急可缩短（费用另计）。
- ⚠️ 软著周期长，建议**与 APP 备案并行启动**，不必等软著下来再备案。

### ⑤ 免责函（今天就能搞定）
- 已为你生成《免责函_模板.md》（见"邀测资料"文件夹）。
- 个人开发者**手写签名**即可，上传到 AppGallery Connect → 版本信息 → 版权信息。
- ⚠️ 请以 AGC 后台实际提供的官方《免责函》模板为准（内容实质一致）。

### ⑥ 打 .app 包 + 提交邀测
- 用**发布证书**（非调试证书）打 **.app 格式**包（邀测需 .app）。
- 包名 bundleName 与备案、AGC 创建应用时**三方一致**。
- 上传 → 填应用信息/版本信息 → 创建测试用户列表 → 发布"邀请测试"版本 → 提交审核。
