# 南医助手（NJMU-Helper）华为应用市场邀测 · 资料清单与流程

> 适用：HarmonyOS 应用（.hap / .app 包）在 AppGallery Connect 发起**开放式测试（Open Testing）**，即"邀测"。
> 依据：华为开发者联盟官方文档（来源链接见文末），整理时间 2026-10-18。

---

## 一、先说结论：你要做的是"开放式测试"，不是"游戏内测"

| 概念 | 适用对象 | 你的情况 |
|---|---|---|
| 开放式测试（Open Testing） | 普通应用 / 元服务 | ✅ **南医助手走这里** |
| 游戏内测（Early Access） | 游戏（APK/APP） | ❌ 不适用 |
| 企业内部应用 | 不公开发布、面向企业特定人群 | ❌ 不适用 |

开放式测试两条路线（二选一，影响审核速度和人数上限）：

| 模式 | 是否跳过人工审核 | 测试人数上限 | 审核时长 |
|---|---|---|---|
| 内部测试（勾选"跳过人工审核"） | 自动审核，速度快 | **100 人** | 数小时 |
| 开放式测试（不勾选） | 需人工审核 | **5000 人** | 1–3 个工作日 |

> 建议：先走**内部测试（≤100人）**快速验证；稳定后再放开到 5000 人。

## 二、前置门槛（不满足就无法提审，务必先办）

1. **华为开发者账号**：注册 HUAWEI ID，完成开发者实名认证（个人用身份证+银行卡，企业用营业执照）。个人账号与企业账号二选一、认证后不可互转。
2. **APP 备案（ICP 备案）**：按工信部《移动互联网应用程序备案工作的通知》，APP 主办者必须完成备案，未备案不得上架。个人开发者也可备案。
3. **软件著作权 / 免责函（二选一，中国大陆必填）**：
   - 非游戏应用 → 必须提供《免责函》（模板华为可下载，盖章/签字）。
   - 强烈建议同时申请《计算机软件著作权登记证书》，既是资质加分项，也是知识产权保护。
4. **隐私政策**：你的应用采集大量个人信息（学号、姓名、成绩、课表、头像），**必须**提供可公开访问的隐私政策 URL，并在应用内提供入口。

> ⚠️ 南医助手特殊风险点：应用通过抓取教务系统（jxglc.njmu.edu.cn）获取数据，涉及**第三方账号登录与数据采集**。审核时需在"备注/给审核员的信息"中说明数据来源与合规性，否则易被驳回。

## 四、完整操作流程（7 步）

### 第 1 步：注册并认证华为开发者
1. 访问 developer.huawei.com，注册 HUAWEI ID。
2. 完成开发者实名认证（个人：身份证+银行卡；企业：营业执照）。
3. 认证通过（1–2 个工作日）后登录 **AppGallery Connect**。

### 第 2 步：完成 APP 备案
1. 到工信部备案系统完成 APP 备案（备案主体与开发者一致）。
2. 备案通过后拿到备案号，供审核填写。

### 第 3 步：创建应用并配置签名
1. AppGallery Connect → "APP 与元服务" → 创建应用。
2. 选择 **HarmonyOS 应用**，填写**包名 bundleName**（务必与代码一致，首版后不可改）。
3. 配置**应用签名证书**（用**发布证书**，不是调试证书），记录 SHA-256 指纹。

### 第 4 步：准备并上传应用包
1. DevEco Studio 用**发布证书**打 **.app 格式**包（邀测需 .app，不是调试 .hap）。
2. 应用包要求：API 版本 ≥10；无 debug 信息；包大小 ≤4GB（手机）。
3. 上传到 AppGallery Connect → "分发 > 应用上架 > 包管理"。

### 第 5 步：填写应用信息与版本信息
按 3.2、3.3 清单逐项填写，**务必**：
- 提供测试账号（教务登录用）
- 隐私政策 URL + 应用内隐私入口
- 免责函/软著
- 备注说明教务数据来源

### 第 6 步：创建测试用户列表并发布测试版本
1. "应用测试 > 测试用户" → 新建列表，添加测试用户华为账号（≤100 或 ≤5000）。
2. "版本信息" → 创建新版本，上架类型选 **"邀请测试"**。
3. 填写测试信息（测试期、反馈邮箱、邀请有效期）。
4. 提交审核。

### 第 7 步：审核通过后邀请用户
1. 内部测试：数小时出结果；开放测试：1–3 个工作日。
2. 通过后到达测试开始时间，系统自动发邮件/短信邀请（或手动触发）。
3. 测试用户点击邀请链接接受 → 安装 .app 测试。

## 五、审核时长与常见驳回点

| 环节 | 时长 |
|---|---|
| 开发者认证 | 1–2 个工作日 |
| 开放式测试人工审核 | 1–3 个工作日 |
| 内部测试自动审核 | 数小时 |

**南医助手最容易踩的坑（提前规避）：**
1. ❌ 未备案就提审 → 直接驳回。
2. ❌ 无隐私政策 / 隐私政策不覆盖教务数据采集 → 驳回。
3. ❌ 无免责函（大陆非游戏必填）→ 驳回。
4. ❌ 包名与 AGC 创建不一致 / 用调试证书签名 → 上传失败。
5. ❌ 教务系统登录无法被审核员访问（未提供测试账号）→ 驳回。
6. ❌ 应用抓取第三方（南医大教务）数据，未在备注说明合规性 → 可能驳回。
