# 南医助手（NJMU-Helper）应用市场文案

## 一、应用名称
南医助手

## 二、简短简介（≤25 字，建议）
南医大学生的教务查询助手

（备选：南京医科大学成绩课表查询工具）

## 三、完整简介（≤8000 字）

南医助手是一款专为南京医科大学学生打造的教务信息查询工具，让您在手机上快速、便捷地获取校园学习信息。

**核心功能：**

1. **成绩查询**：一键查询学期成绩、总评成绩、学分绩点，成绩状态一目了然。
2. **课表查看**：随时查看本学期课程安排，支持实践课、公共选修课等完整课程展示，未排课课程清晰归类。
3. **校历展示**：内置官方校历，自动标注周次，支持工作日、节假日、调休安排展示。
4. **空闲教室查询**：快速查找空闲教室，合理安排自习与活动。
5. **个人信息**：展示学籍信息与个人头像。

**产品特点：**
- 数据来源于南京医科大学官方教务系统，信息权威可靠。
- 界面简洁清晰，操作流畅，专注学生核心需求。
- 本地化数据存储，保护您的个人信息安全。

**温馨提示：**
- 使用本应用需使用南京医科大学教务系统账号登录。
- 本应用为非官方第三方工具，数据最终以学校教务系统为准。
