# 备案版站点改造清单

> 前提：走个人备案（路径 B）。审核员会打开网站逐页看，站名、标题、内容、主体必须能对上。
> 现状统计（`website/` 五页）：出现「南医」56 次、「南京医科大学」19 次、「NJMU」47 次、备案号 0 处。

---

## 一、先定站名

个人备案站名规则（江苏，接入商执行口径）：3 字以上，不得纯英文/纯数字/特殊符号，不得含单位名称及简称、地名、人名、行业词、域名；常见可过口径是「某某的个人博客 / 某某的个人主页」。带「助手」「工具」「课程表」这类泛词，各省松紧不一，江苏偏严。

| 候选 | 能否带「南医」 | 评价 |
|---|---|---|
| 南医助手 | 否 | 个人备案大概率退回，不建议 |
| NJMU Helper / NJMU 课表 | 否 | 含校名缩写，且全英文不合规 |
| 课表小助手 | 否 | 可能被认定过泛，江苏需备注意说明 |
| 某某的个人主页 | — | 江苏最稳口径，最不像产品站 |
| 某某的技术笔记 | — | 稳，但和站点内容不符，反而容易问 |

**建议**：备案名用「【你的名字】的个人主页」，网站副标题写「课程表工具介绍」；备案通过后再评估是否申请变更名称。不要为了好看硬填「南医助手」，退回一次至少多等一周。

## 二、文件级改动

| 文件 | 改动点 | 具体做法 |
|---|---|---|
| 全部 5 页 `<head>` | `<title>`、`meta description` | 去掉「南京医科大学」「南医」，改为「课程表工具介绍」「高校课表助手」等中性表述 |
| 全部 5 页页脚 | 品牌名、免责声明 | 「南医助手 · NJMU-Helper」→ 中性站名；免责声明中保留「非官方、数据以学校官方系统为准」但不指向具体校名 |
| `index.html` | hero 标题与副标题 | 「把南医装进口袋」→「把课表装进口袋」；正文去掉校名，「教务系统」改为「学校教务系统」 |
| `index.html` | 图标与校徽 | `assets/icon.png` 若含校徽元素，备案版换中性图标；校徽属单位标识，个人站不宜使用 |
| `features.html` | 功能文案 | 「快捷选课 · 选课季的秘密武器」→「选课辅助」；删「抢课」「检漏模式」「自动提交」等表述 |
| `shots.html` | 截图 | 截图内若出现校名、学号、姓名，先打码再上线（学号示例 `24220199` 需确认是否为真实信息） |
| `opensource.html` | 仓库链接 | 仓库路径含 `NJMU-Helper`，可保留（代码托管平台不在审核范围），但页面文案不要强调校名 |
| `privacy.html` | 主体信息 | 补「网站主办者：个人」「联系邮箱」「备案号」；说明不收集访问者个人信息、日志留存 6 个月 |
| 新增 `about.html` | 关于本站 | 说明站点性质、内容来源、非官方声明、联系方式（见下） |

> 如果不想大改：至少把「站名 + 首页标题 + 页脚」三处中性化，其余保留。风险是审核员看到站内 56 处「南医」时追问，需临时整改，等于多一轮。

```html

<p>本站是个人开发者维护的静态介绍页，用于说明一款高校课程表工具的功能与使用方式，不提供注册、登录、评论或任何交易功能。</p>

<p>本站为非官方作品，与任何高校无隶属或合作关系，相关名称与标识归其权利人所有。</p>
<p>联系邮箱：<a href="mailto:peng24@stu.njmu.edu.cn">peng24@stu.njmu.edu.cn</a></p>
```

> 联系邮箱用学校邮箱没问题（个人身份可核验），但页面上不要写「南京医科大学官方」之类表述。

## 六、上线顺序（别搞反）

1. 备案通过前：新域名**不解析**，站点继续跑 GitHub Pages / WorkBuddy。
2. 备案通过后：DNS 解析到境内服务器 → 部署中性版 → 全站 HTTPS → 页脚挂备案号。
3. 上线 30 日内：做公安联网备案。
4. 品牌站（含校名）继续留在 GitHub Pages，与备案站并存；两个站内容差异不要大到被认定「备案信息与实际不符」。

> 若想把品牌站也放到自有域名下，需先解决校名授权，否则不建议。

## 七、验收自查

- [ ] 站名与备案表一致，首页 `<title>` 与站名一致
- [ ] 全站不出现「南京医科大学」「南医」作为站点名称（客观指称也建议去掉）
- [ ] 无注册、登录、评论、表单
- [ ] 无「抢课」「绕过」「破解」「自动提交」类表述
- [ ] 隐私政策公网可访问，内容与 App 行为一致
- [ ] 页脚备案号可点击跳转
- [ ] 截图无真实学号、姓名、成绩
- [ ] HTTPS 正常，HTTP 自动跳转
- [ ] 服务器仅开放 80/443
