# App 备案清单（com.njmu.helper）

> 依据：工信部信管〔2023〕105 号。境内分发（应用商店、站内直下、预置）必须先备案；未备案不得分发。
> App 备案可与网站备案解耦：先做网站备案的主体，再补 App 信息即可，不必重复提交身份证等主体材料。

---

## 一、本项目要填的技术信息

| 字段 | 取值 | 从哪里取 |
|---|---|---|
| App 名称 | 南医助手 | `AppScope/app.json5` → `label` |
| 包名 | `com.njmu.helper` | `AppScope/app.json5` → `bundleName` |
| 版本 | 2.0.3（versionCode 见 app.json5） | 同上 |
| 应用图标 | 512×512 PNG | `website/assets/icon.png` |
| 签名证书 MD5 / SHA-256 | 【待导出】 | `keytool -list -v -keystore <p12> -alias <alias>` |
| 签名公钥 | 【待导出】 | 同上 |
| 权限清单 | 网络、存储（备份导入导出）、日历（写日程）等 | `entry/src/main/module.json5` → `requestPermissions` |
| 第三方 SDK | 无统计、无推送、无广告 SDK | 全工程依赖核查后填写 |
| 隐私政策 URL | `https://<备案域名>/privacy.html` | 需公网可访问 |
| 服务器域名 / IP | 【待确认】 | 见下节 |

**待确认项**：App 目前无自有后端，数据直连学校教务系统。备案表要求填写 App 使用的域名/IP，建议按以下顺序处理：

1. 先向**分发平台备案专员**（华为应用市场或代提交的商店）确认：纯客户端、无自有服务器时该字段如何填写；
2. 若有网站备案域名，优先填该域名（站点本身也提供 App 介绍与下载）；
3. 不要留空，也不要自行填写学校系统域名而不说明用途（易被要求补充授权材料）。

## 二、前置审批判断

| 类别 | 是否触发 | 说明 |
|---|---|---|
| 新闻 | 否 | 应用内聚合的是学校官网公开信息，不自采自编 |
| 出版 / 网络文学 | 否 | 无 |
| 教育（办学、在线教育） | 否（边界项） | 提供课表、成绩查询，不提供课程教学服务；若后续加课程视频需重新评估 |
| 医疗保健 | 否 | 无 |
| 视听 | 否 | 无音视频内容 |
| 电子公告（论坛/社区） | 否 | 无发帖、评论 |

> 名称含「南医」不等于触发前置审批，但可能被要求提供**学校名称使用授权**，属另一类审核（名称权），提前准备更快。

## 五、应用内要加的一行

「我的 / 关于」页底部：

```
备案编号：苏ICP备2026XXXXXX号-XA
https://beian.miit.gov.cn/
```

App 备案编号格式与网站不同，以管局下发为准；展示要求是「显著位置 + 可查询链接」。

---

## 六、顺序建议

1. 先做网站备案（拿到主体备案号）；
2. 用同一主体补 App 备案（信息复用，通常更快）；
3. 备案号下来后更新应用「关于」页，重新打包（版本号 +1，例如 2.0.4）；
4. 再提交商店审核，避免因缺备案号被拒；
5. 站内下载页同步展示备案号。

> 如果时间紧：至少先确认分发平台（华为应用市场 / 第三方商店）当前的备案核验策略，再决定先做哪一头。
