# 南医助手 · 网站与 App 备案方案

> 适用对象：南京医科大学学生个人开发者；站点为静态介绍站（`website/`，5 页 HTML/CSS/JS）；App 为 HarmonyOS NEXT 应用 `com.njmu.helper` v2.0.3。
> 编制时间：2026-10-20。政策与接入商规则会变，提交前以接入商备案系统内展示的最新规则为准。

---

## 一、结论先行

1. **现在的三个地址，一个都备不了案**：GitHub Pages 是境外托管，`*.workbuddy.host` 是平台子域名（域名持有人不是你），`sydxky.cn` 是第三方商店的页面（备案主体是商店）。备案的前提是「自有域名 + 境内接入服务」，与现有三个地址无关。
2. **备案 = 新增一套东西**：自己注册域名 + 买境内服务器（或用境内对象存储）+ 用新域名部署一份站点。
3. **个人备案在江苏，站名是最大障碍**：「南医」「南京医科大学」属单位名称及简称，个人主体不得使用；江苏个人备案的站名，接入商普遍按「某某的个人博客 / 某某的个人主页」口径执行。也就是说，**以个人身份备案，站点不能叫「南医助手」**。
4. **想保留品牌与校名，只有学校主体这一条路**：需南京医科大学（或授权单位）作为主办单位，出具事业单位证件、公章、授权书。学生个人无法代学校备案。
5. **如果目的只是「国内访问快一点」，不建议备案**：GitHub Pages 多数国内网络能打开（速度一般），备案并不会让它变快；备案只对「自有域名 + 境内服务器」有意义。

## 二、现状盘点

| 地址 | 托管方 | 域名持有人 | 是否需要 ICP 备案 | 能否备案 |
|---|---|---|---|---|
| `xiopeng32-ai.github.io/NJMU-Helper/` | GitHub Pages（境外） | GitHub | 不需要（境外托管） | 不能，域名不归你 |
| `njmu-helper-privacy.app.workbuddy.host` | WorkBuddy 托管 | 平台 | 不需要（平台域名） | 不能，子域名不可单独备案 |
| `www.sydxky.cn/detail.php?id=1034` | 第三方应用商店 | 商店运营方 | 由商店自行备案 | 与你无关，你只是被收录 |
| `github.com/.../releases/...hap` | GitHub | GitHub | 不需要 | 不能 |

**结论**：ICP 备案号只能挂在「你实名持有的域名 + 境内接入」上，与上述地址是并行的另一套发布链路。

## 三、三条路径对比

| 维度 | A. 不备案（维持现状） | B. 个人主体备案（江苏） | C. 学校主体备案 |
|---|---|---|---|
| 主办单位 | 无 | 你本人（身份证） | 南京医科大学 / 授权单位 |
| 站名 | 随意 | 受严格限制，不能含校名、行业词；常见口径为「某某的个人博客/主页」 | 可用「南医助手」，需单位授权 |
| 域名 | 不需要 | 需新注册，持有人 = 你 | 需单位持有或出具域名授权 |
| 服务器 | 境外/平台 | 境内，包年包月 ≥ 3 个月 | 学校机房或学校采购的云资源 |
| 周期 | 0 天 | 约 7–20 个工作日（管局法定 20 个工作日） | 1–3 个月（含校内审批） |
| 现金成本 | 0 | 首年约 200–500 元 | 0（用学校资源） |
| 能得到的 | 现状 | ICP 备案号，可绑自有域名国内访问 | 正规备案，可公开使用校名 |
| 主要风险 | 平台政策变动、无自有域名、分发合规缺口 | 站名与品牌脱节；站内校名/校徽可能被要求整改；个人不得涉经营性内容 | 审批不确定；内容需学校审核；可能要求移交运维 |
| 适合场景 | 只是给同学看、不推广 | 想要自己的域名、国内稳定访问、App 备案打底 | 想长期做、要学校背书、进官方渠道 |

**推荐组合**：先按 B 把「域名 + 境内托管 + 备案」跑通（站点用中性名），同时就 C 与学校信息化建设管理处沟通；C 走通后再把品牌名迁回备案信息（做备案变更）。

## 六、七个高风险点（按被退回概率排序）

1. **站名含「南医」**：个人备案高频退回项。校名、校名简称、校徽均属单位标识，个人主体不宜使用。
2. **站内大量出现「南京医科大学」「南医助手」「教务系统」**：审核会打开网站核对，站名与内容、主体不一致会被要求整改；使用学校标识可能被要求提供授权。
3. **提供 `.hap` 下载**：会被视作软件下载站。需能说明来源（自研、MIT 开源、仓库可查），建议公示 SHA256 与签名信息。
4. **「快捷选课 / 抢课 / 检漏」表述**：涉及自动化操作学校选课系统，备案与商店审核都敏感。对外文案改为「选课辅助（按用户设定时间提交）」，不写「绕过限制」「自动抢」。
5. **未备案先解析**：域名一旦解析到境内 IP 即被阻断，且会留下记录。
6. **备案后内容漂移**：抽查发现网站内容与备案信息不符，会被责令整改甚至注销备案。
7. **个人信息合规**：站点目前不收集数据，但若后续加统计、留言、登录，需同步改隐私政策；App 端涉及学号成绩，按《个人信息保护法》单独说明。

## 七、备案后的持续义务

- 页脚展示：`苏ICP备XXXXXXXX号-X`，并链接 `https://beian.miit.gov.cn/`。
- 30 日内完成公安联网备案，页脚同时展示公安备案号与链接。
- 主体信息、网站名称、域名、服务器 IP、负责人联系方式变更时，20 日内办理变更备案。
- 网站停止服务时办理注销备案，否则可能被列入异常。
- 日志留存不少于 6 个月（《网络安全法》第二十一条）。
