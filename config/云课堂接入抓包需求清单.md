# 南医云课堂接入抓包需求清单

目标：把 https://zjy.njmu.edu.cn/ICloudPortal/ （云课堂）接入南医助手 App。
请登录后用浏览器 DevTools（F12 → Network，勾选 Preserve log）或抓包工具采集以下内容，整理成类似《教务培养方案与学业情况抓包记录.md》的文档。

## 1. 登录与认证链路（最关键）

- [ ] 登录入口 URL 与跳转链路：从 App/门户进入云课堂的完整 302 跳转序列（哪一步 SSO、哪一步发 ticket）
- [ ] 认证方式判断：是否复用统一身份认证 authserver.njmu.edu.cn（金智 CAS），还是独立账号体系（超星/学习通/雨课堂等第三方？）
  - 若是超星（Chaoxing）：抓 `passport2.chaoxing.com` 相关请求与 cookie（fid/uid/d、Darkroute 等）
  - 若是学校自建：抓完整 cookie 集合与过期规律
- [ ] 会话 Cookie 清单：名称、作用域、时效（哪几个缺一不可）
- [ ] SSO 桥接端点：类似教务的 `/sso/jzlogin`，确认云课堂的 ticket 校验地址与参数格式

## 2. 课程与任务点接口

- [ ] 「我的课程」列表接口：URL、请求方法、参数（学期/页码）、响应 JSON 结构（课程 id、名称、教师、进度字段）
- [ ] 课程详情/章节目录接口：章节树结构、任务点（视频/作业/测验/讨论）类型标识
- [ ] 学习进度接口：进度百分比字段、未完成任务标识
- [ ] 作业与考试列表接口：待完成/已截止/已批阅状态字段

## 3. 通知与截止提醒（如需推送）

- [ ] 公告/通知接口：列表 URL 与字段
- [ ] 截止时间字段格式（时间戳 or 字符串、时区）

## 4. 播放器（如需在 App 内看视频）

- [ ] 视频源地址格式（m3u8/mp4？是否有防盗链 token、有效期）
- [ ] 是否有 referer/加密参数校验（决定 App 内嵌 WebView 还是外链跳转）

## 5. 环境特征

- [ ] 请求头要求：UA、Referer、X-Requested-With 等（哪些接口校验）
- [ ] 接口域名清单（可能多个域：门户域 + 资源 CDN 域）
- [ ] 是否有前端加密参数（类似教务无 gid_ 的结论要重新验证一遍）

## 采集操作提示

1. 先清空 Network 记录 → 完整走一遍「登录 → 进云课堂 → 打开一门课 → 看一个章节」
2. 每个关键请求右键 Copy → Copy as cURL（含 headers）
3. 响应体保存为 JSON（列表页 + 详情页各一份）
4. 特别标注：哪一步出现新 Cookie、哪一步是 302
