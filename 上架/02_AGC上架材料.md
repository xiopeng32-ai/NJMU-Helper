## 二、商店文案（可直接粘贴）

**应用名称**：南医助手

**一句话简介**（≤ 30 字）：
> 课表、成绩、学业、考试，一个鸿蒙应用全搞定。

**应用介绍**：

```
南医助手是一款面向高校学生的鸿蒙原生校园工具。课表、成绩、学业进度、考试安排、空教室查询与校园资讯集中在一个应用里，打开就知道今天上什么、下周考什么、离毕业还差多少学分。

【课表】15 节完整作息，彩色课程块区分科目，周次一键切换，支持整学期写入系统日历并课前提醒。
【成绩与学业】平均学分绩点、累计学分、成绩分布、等级考试一屏读完，支持导出成绩单长图。
【考试与教室】考试时间地点座位与倒计时，按楼栋和节次筛选空教室。
【校园资讯】学校官网公告与学院通知聚合，分类浏览，可跳转原文。
【桌面卡片】今日课程、考试倒计时抬手即见。

应用为鸿蒙原生开发，安装包约 8.4 MB，无广告、无推送、无内购。账号仅用于向学校系统发起登录，不经过任何第三方服务器；课表与成绩只保存在本机，可随时清空或加密备份。

本应用由学生个人开发并开源（MIT），非学校官方应用，数据以学校官方系统为准。
```

**更新说明**（本版）：
```
· 全新界面与更顺滑的动效
· 新增今日课表、云课堂
· 支持平板与 2in1 多栏布局
· 修复已知问题
```

**审核备注**（写给审核员，务必填）：
```
1. 本应用面向南京医科大学在读学生，登录需使用学校教务系统账号，无公开测试账号。审核如需验证，可跳过登录查看「关于」「隐私政策」等页面；登录相关功能不在本次审核范围。
2. 应用内所有数据仅保存在设备本地，不上传第三方服务器，可在「我的 → 清空数据」删除。
3. 权限用途：网络（获取课表成绩）、网络状态（断网提示）、日历读写（写入课程与考试提醒）。
4. 桌面卡片：长按桌面 → 服务卡片 → 搜索「南医助手」添加。
5. 应用为非官方学生作品，已在关于页与应用介绍中声明。
```

## 四、资质：软著到底要不要

- 华为官方《应用资质审核要求》原文：**「APP 软件著作权证书为非必选资质」**，建议申请以保护知识产权。
- 实际提审时，AGC「版权信息」处可上传《计算机软件著作权登记证书》《APP 电子版权认证证书》或《软件著作权认证证书》三者之一。
- 结论：**先不花钱办**。若审核明确要求，再走中国版权保护中心官方通道（0 元，20–40 工作日，电子证书）；赶时间再找代理加急（300–800 元）。

> 需要的话我可以生成软著申请用的源代码文档（前 30 页 + 后 30 页）与软件说明书，避免找代理。
