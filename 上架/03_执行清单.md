## 阶段 1 · 资源到位后（1–2 天）

- [ ] 定站名（中性、3 字以上、不含校名）
- [ ] 用中性版站点替换 `website/` 的标题与页脚（`备案/03_站点改造清单.md`）
- [ ] 备案系统提交**网站备案**，字段照 `上架/01_备案字段表.md` 填
- [ ] 上传身份证、核验单、建设方案书（`备案/02_网站建设方案书.md`）
- [ ] 完成人脸核验
- [ ] 接听接入商初审电话（口径见字段表）
- [ ] 24 小时内完成工信部短信核验

## 阶段 2 · 管局审核期（5–20 工作日，期间做这些）

- [ ] 统一版本号：`AppScope/app.json5`、`AboutPage.ets`、商店文案三处一致
- [ ] 用统一后的版本重新构建 Release 签名包
- [ ] 导出公钥与 MD5（`上架/01_备案字段表.md` 第三节命令）
- [ ] 核对 AGC 素材：`上架/AGC素材/` 已备好图标与截图
- [ ] 截图脱敏：确认无真实学号、姓名、成绩
- [ ] 准备隐私政策 URL（备案通过后即可访问）
- [x] 应用内「关于」页加备案号展示位（`AboutPage.ets` 的 `icpNo`，拿号后填入即显示）

## 阶段 3 · 备案通过（当天）

- [ ] 域名解析到服务器，部署站点，开 HTTPS
- [ ] 页脚挂 ICP 备案号（可点链接 `https://beian.miit.gov.cn/`）
- [ ] 备案系统追加 **App 备案**：平台选「鸿蒙」，填包名、公钥、MD5、隐私政策
- [ ] 等 App 备案号（通常快于首次网站备案）
- [ ] 应用「关于」页填 App 备案号，重新打包
- [ ] AGC 创建应用 → 上传包 → 填素材与文案（`上架/02_AGC上架材料.md`）
- [ ] 填备案号并点「校验」
- [ ] 提交审核

## 阶段 4 · 上线后 30 日内

- [ ] 公安联网备案：<https://www.beian.gov.cn/>
- [ ] 页脚加公安备案号
- [ ] 应用详情页展示备案号（平台侧）
- [ ] 记录首版发布时间，后续每次发版同步更新备案信息（名称、包名、版本）
