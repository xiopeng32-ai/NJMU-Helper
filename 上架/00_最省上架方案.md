# App 上架 · 最省方案

> 目标：把 `com.njmu.helper` 上架华为应用市场（AppGallery）。只算为了「能上架」必须花的钱。
> 编制时间：2026-10-20。价格是活动价区间，以购买当天为准。

---

## 一、结论

| 项目 | 是否必须 | 最省花费 | 说明 |
|---|---|---|---|
| 华为开发者账号（个人实名） | 必须 | **0 元** | 个人实名免费 |
| App 备案 | 必须 | **0 元** | 管局不收费；前提是有境内接入资源 |
| 域名 | 必须 | **约 9–30 元/年** | 备案要有域名；`.top` 首年最便宜 |
| 境内服务器（备案用） | 必须 | **约 88–99 元/年** | 轻量 2 核 2G 新客价，需包年包月 ≥ 3 个月 |
| 软件著作权 | 官方口径非必选 | **0 元**（自办） | 官方审核要 20–40 工作日；代理加急 300–800 元 |
| ICP 许可证 | 不需要 | 0 | 非经营性，不收费不卖会员就不办 |
| 企业开发者认证 | 不需要 | 0 | 工具类个人可上架 |
| CDN / 高配服务器 / 短信 | 不需要 | 0 | 静态站 1 核够用 |

**首年合计：约 110 元**（域名 10 + 轻量 99 + 备案 0 + 账号 0 + 软著 0）。
**次年：** 域名 30 + 服务器续费 200–400（建议直接买 3 年促销，摊到每年更低）。

周期：备案 5–20 个工作日 + 华为审核约 1 个工作日。**预留 3–5 周**。

## 二、为什么你的 App 必须备案

华为官方口径（[应用审核 Checklist](https://developer.huawei.com/consumer/cn/doc/50170)）：

- 服务器在中国大陆、且上架国内渠道 → 必须 App 备案；
- **单机应用**（未通过公共互联网提供信息服务）与境外应用可免备案；
- 鸿蒙版备案要在接入商系统里选「鸿蒙」平台并填包名。

你的 App 登录学校教务系统、拉取课表成绩，属于联网服务，**不能按单机应用免备案**。

## 三、三条路径对比

| 路径 | 花费 | 能否上架华为 | 适用 |
|---|---|---|---|
| **A. 域名 + 最便宜轻量 + 个人备案（推荐）** | 首年约 110 元 | 能 | 目标就是上架 |
| B. 只做 App 备案、不建站 | 还是约 110 元 | 能 | 省不了钱，反而少一个隐私政策托管点 |
| C. 不备案，只发 GitHub / 第三方商店 | 0 元 | **不能**，AGC 会拦 | 放弃上架 |

> B 与 A 成本几乎一样：备案系统需要接入资源（备案服务码），服务码来自云服务器，所以服务器省不掉。既然买了服务器，顺手把介绍站搬上去，隐私政策 URL 也更稳。

## 五、省钱要点

1. **域名后缀**：`.top` 首年常见 1–9 元，`.xyz` 约 6–10 元，`.cn` 约 25–35 元。都可用于备案（必须在工信部批复后缀名单内）。续费价才是长期成本，`.top` 约 30 元/年。
2. **服务器只买最低配**：静态站 + 备案，2 核 2G 是起步配置，1 核 1G 也够；别买带宽超 5M 的套餐。
3. **一次买 3 年**：新客 3 年促销常比「首年 99 + 续费 400」便宜一半。
4. **软著先不办**：华为官方《应用资质审核要求》写明「APP 软件著作权证书为非必选资质」。被要求时再走中国版权保护中心官方通道（0 元，20–40 工作日）。
5. **别买 CDN、别买短信包、别买 SSL**：Let's Encrypt 或云厂商免费 DV 证书够用。
6. **备案免费**：任何声称「代办备案收费」的都是加价服务，自己填 1 小时能完成。

## 六、最容易卡住的 6 件事

| 风险 | 影响 | 处理 |
|---|---|---|
| 江苏个人备案站名含「南医」 | 退回，多等一周 | 用中性站名（`备案/03` 有候选） |
| App 名称与备案名称不一致 | AGC 校验失败 | 备案时就填「南医助手」，包名一致 |
| 版本号三处不一致 | 审核质疑包来源 | 当前源码 `1.9.9`、关于页写 `1.9.4`、站内 hap 是 `2.0.3`，**先统一** |
| 手机截图不是 9:16 | 素材校验不过 | 已生成 1080×1920 版本，见 `上架/AGC素材/screenshots/` |
| 隐私政策打不开 | 审核驳回（必备项） | 用 `https://<你的域名>/privacy.html`，备案后即可访问 |
| 选课功能表述 | 审核质疑自动化 | 改为「选课辅助」，不写「抢课」「绕过」 |
